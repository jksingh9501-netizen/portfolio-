# Add your images here

Keep your image files in this `assets` folder. The website looks for these exact names:

## Most important first
- `hero-skyline.jpg` - cinematic sunset/city background for the hero
- `manpreet-hero.png` - Manpreet cut out with a transparent background, full body, front/3-quarter pose
- `about-studio.jpg` - wide creative desk/studio image for the About section
- `manpreet-working.png` - transparent character image of Manpreet sketching/working
- `skills-studio.jpg` - wide dark studio image for the Skills section
- `contact-window.jpg` - warm window/sunset scene for Contact

## Project artwork
- `project-website-01.jpg` - screenshot/mockup for Website 01
- `project-website-02.jpg` - screenshot/mockup for Website 02
- `project-graphic-01.jpg` - graphic/illustration project
- `project-graphic-02.jpg` - poster or campaign design
- `project-graphic-03.jpg` - UI or graphic project
- `project-graphic-04.jpg` - packaging or branding project
- `hero-city.png` - optional transparent city skyline layer

## Image tips
- Use JPG for photographs and project mockups.
- Use PNG for Manpreet when you need transparency.
- For the hero, a wide image around 1920 x 1200 px works well.
- For project cards, 1200 x 900 px (4:3) is a useful starting size.
- Don't rename files unless you also update their paths in `style.css` or `index.html`.

Until the files are added, CSS gradients and simple mockups keep the page layout visible. The character placeholder disappears once `manpreet-hero.png` is found.
